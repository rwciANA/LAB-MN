Módulo 3 · Aproximación de funciones

Interpolación y ajuste de curvas

Distingue pasar por los datos de aproximar una tendencia, y elige el método según lo que necesites.

Objetivo: distinguir interpolar de ajustar, y elegir entre ambos según el propósito.

Caso de partida (datos sintéticos): carga normalizada x = 0, 1, 2, 3 y latencia y = 1, 2, 2, 4 ms de un servicio.

1. Teoría breve

Interpolación de Lagrange

Construye un polinomio de grado n − 1 que pasa exactamente por los n puntos:

$$P(x)=\sum_{i=0}^{n-1} y_i\,L_i(x), \qquad L_i(x)=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}$$

Limitación: si el dato tiene error de medición, el polinomio lo reproduce. Con grado alto puede oscilar entre puntos.

Regresión lineal por mínimos cuadrados

Busca la recta que minimiza la suma de cuadrados de los residuos, sin pasar necesariamente por los datos:

$$\text{pendiente } b=\frac{S_{xy}}{S_{xx}},\qquad \text{intercepto } a=\bar y-b\,\bar x,\qquad SCR=\sum_i (y_i-a-b\,x_i)^2$$

Limitación: requiere al menos dos abscisas distintas; supone una tendencia lineal.

Idea clave: interpolar no elimina el error de medición. Ajustar sirve para describir una tendencia; interpolar, para estimar entre datos exactos.

3. Ejemplo resuelto y caso comparativo

  1. Lagrange con los cuatro nodos. En x = 1.5 el polinomio vale 1.9375 ms.
  2. Regresión lineal. Sxy = 4.5 y Sxx = 5, así que b = 0.9 y a = 0.9. La recta es y = 0.9 + 0.9x; predice 2.25 ms en x = 1.5.
  3. Interpretación. No coinciden porque tienen objetivos distintos: Lagrange respeta cada dato (incluido el 2 en x = 2) y la recta describe la tendencia general. Si la latencia real tiene ruido, la recta es el modelo más estable para predecir.
