02 TEORÍA

Interpolar frente a ajustar

Dos modelos con objetivos distintos. Elegir mal el modelo lleva a conclusiones erróneas.

Lagrange

Polinomio de grado a lo sumo $n-1$ que pasa por los $n$ puntos:

$$P(x)=\sum_{i=0}^{n-1} y_i\,L_i(x),\qquad L_i(x)=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}$$

Limitación: reproduce el error de medición y, con grado alto, puede oscilar entre puntos.

Regresión lineal

Recta que minimiza la suma de cuadrados de los residuos:

$$b=\frac{S_{xy}}{S_{xx}},\qquad a=\bar y-b\,\bar x,\qquad SCR=\sum_i (y_i-a-b\,x_i)^2$$

Limitación: requiere al menos dos abscisas distintas y supone una tendencia lineal.

Idea clave

Interpolar no elimina el error de medición. Ajustar describe una tendencia para predecir; interpolar estima entre datos exactos. Fuera del intervalo de los datos, ambos requieren aviso de extrapolación.

04 EJEMPLOS RESUELTOS

Paso a paso

El caso de partida y ejemplos adicionales con contribuciones de cada base y comparación de nodos.

Caso de partida · Lagrange y regresión

  1. Lagrange con cuatro nodos. En x = 1.5 el polinomio vale 1.9375 ms.
  2. Regresión lineal. Sxy = 4.5 y Sxx = 5, así que b = 0.9 y a = 0.9. La recta es y = 0.9 + 0.9x; predice 2.25 ms en x = 1.5.
  3. Interpretación. No coinciden porque tienen objetivos distintos: Lagrange respeta cada dato y la recta describe la tendencia.

Conclusión

Si los datos son exactos y quieres reproducirlos, interpola. Si tienen error de medición y buscas una tendencia para predecir, ajusta. En ambos casos, la consulta fuera del intervalo requiere aviso.
