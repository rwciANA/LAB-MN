# Entregable 1: Ecuaciones no lineales

Prototipo web educativo del módulo de Bisección y Newton para el laboratorio de Métodos Numéricos.

## Contenido

- Portada con el caso aplicado `f(x) = x^3 - x - 2` en `[1, 2]`.
- Teoría resumida de Bisección y Newton.
- Calculadoras funcionales con tolerancia, límite de iteraciones y validación.
- Tabla de iteraciones, gráfico de convergencia y descarga CSV.
- Cuatro ejercicios de práctica con retroalimentación.
- Acta de equipo y ruta del Entregable 1.

## Ejecución

Abrir `index.html` en un navegador moderno. Las librerías Chart.js y Font Awesome se cargan desde CDN, por lo que se requiere conexión a internet para mostrar gráficos e iconos.
