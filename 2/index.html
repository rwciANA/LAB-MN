02 TEORÍA

Cómo funcionan ambos métodos

Dos formas de llegar a la misma solución: una directa y otra por aproximaciones sucesivas.

Eliminación gaussiana con pivoteo parcial

En cada columna $k$ se elige como pivote la fila con mayor $|a_{ik}|$ y se intercambia con la fila $k$. Luego se anulan los elementos debajo del pivote y se despeja de abajo hacia arriba:

$$x_n=\frac{b_n^{(n)}}{a_{nn}^{(n)}},\qquad x_i=\frac{b_i^{(i)}-\sum_{j>i}a_{ij}^{(i)}x_j}{a_{ii}^{(i)}}$$

Advertencia: si el pivote es cero el sistema es singular. Si es muy pequeño, el error de redondeo se amplifica.

Gauss-Seidel

Cada componente usa los valores más recientes disponibles:

$$x_i^{(k+1)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{ji}a_{ij}x_j^{(k)}\Big)$$

Criterio de parada: $\|b-Ax\|_\infty\le\text{tol}$, o agotar el máximo de iteraciones. Llegar al máximo no demuestra convergencia.

Dominancia diagonal estricta

Si $|a_{ii}|>\sum_{j\ne i}|a_{ij}|$ en cada fila, Gauss-Seidel converge. Es una condición suficiente, no necesaria: la matriz $\begin{pmatrix}2&1&0\\1&2&1\\0&1&2\end{pmatrix}$ es simétrica definida positiva y converge aunque su fila 2 no sea estrictamente dominante ($2=1+1$).

Cuándo usar cada uno

Eliminación gaussiana para sistemas pequeños y densos como los de este módulo. Gauss-Seidel cuando la matriz es grande y dispersa y se conoce que converge, por ejemplo con dominancia diagonal estricta.
