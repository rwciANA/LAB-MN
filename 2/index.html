Objetivo: resolver sistemas pequeños y comparar un método directo con uno iterativo mediante el residuo.

Caso de partida (datos sintéticos): demanda de tres servicios con filas (4, 1, 1), (1, 5, 1), (1, 1, 6) y vector (9, 14, 21). Las incógnitas son índices normalizados de demanda.

1. Teoría breve

Eliminación gaussiana con pivoteo parcial

Convierte A·x = b en un sistema triangular superior. En cada columna se intercambia la fila con mayor |valor| para usar el pivote más grande posible. Luego se despeja la última incógnita y se sustituye hacia atrás.

Limitación: un pivote cercano a cero amplifica el error de redondeo, y un pivote nulo indica sistema singular.

Gauss-Seidel

Método iterativo: cada componente se actualiza con los valores más recientes disponibles. Parte del vector cero y se detiene cuando la norma infinita del residuo $$\|b - A x\|_\infty \le \text{tol}$$ cumple la tolerancia.

Condición suficiente: si la matriz es estrictamente diagonal dominante (|aᵢᵢ| > Σ|aᵢⱼ| en cada fila), Gauss-Seidel converge. No es necesaria: hay sistemas convergentes que no cumplen esta condición.

3. Ejemplo resuelto y caso comparativo

  1. Verificar la solución exacta. Con x = (1, 2, 3): fila 1 → 4·1 + 1·2 + 1·3 = 9 ✓; fila 2 → 1 + 10 + 3 = 14 ✓; fila 3 → 1 + 2 + 18 = 21 ✓.
  2. Primera iteración de Gauss-Seidel desde cero. x₁ = 9/4 = 2.25; x₂ = (14 − 2.25)/5 = 2.35; x₃ = (21 − 2.25 − 2.35)/6 = 2.7333…
  3. Comparación. Ambos métodos llegan a (1, 2, 3). El directo lo hace en un número fijo de operaciones y deja residuo cero dentro del redondeo; Gauss-Seidel necesita varias iteraciones y el residuo baja en cada una.
